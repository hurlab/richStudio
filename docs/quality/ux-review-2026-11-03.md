## Verdict
The engine grew (input review, job registry, projects) but the UI grew by stacking panels onto the old dashboard. Every screen opens with a tall "active workspace" card and an unstyled job log; real work starts 450-830 px down. Several views say "No data to display" above populated output. Copy mixes biology with developer internals. Most fixes are layout/copy, not engine.

## Structural proposals
A. Task stepper 1 Data -> 2 Enrich -> 3 Results -> 4 Cluster -> 5 Save with per-step status and next action.
B. Single context bar (dataset switcher, metadata chips, job badge) opening a slide-over job tray; replaces the workspace card and job log.
C. Results as master-detail: term table left, linked figure right, plot type as a segmented control, settings collapsed above the figure.
D. One box style, one accent colour, semantic colours for status only (--rs-* tokens exist).
E. Progressive disclosure: plain-language defaults ("adj. p < 0.05 - background: all annotated genes") with "Adjust"; the current review card becomes Advanced.
